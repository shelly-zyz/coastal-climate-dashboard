# 中国沿海气象可视化大屏

中国沿海地区 2021-2030 年气候投影可视化，基于 Next.js、React、Three.js 和 Recharts。

## 当前版本

在原版之上增加四张气象主题卡、省份对比榜、年际对比、年月热力矩阵和季节特征。顶部指标与两侧模块随年份、区域和地图模式联动；日历支持选择 2021–2030 年月份，省份表格展示实际涨跌箭头。详见 [数据与联动说明](docs/dashboard-insights.md) 和 [界面优化说明](docs/impeccable-refinement.md)。

## 原始备份版本

本仓库的初始提交及备份标签保存信息量扩展之前的网站，包括完整中国立体地图、连续热力颜色、年度播放、省份查询和气象统计图表。以下描述针对备份标签：

- 点击地图仅选中省份并显示数值，不自动放大。
- 从“省份查询”下拉框选择省份时，地图自动聚焦。
- 顶部五项指标在此备份中是固定的十年均值，尚未接入年份或区域联动。
- 四张气象主题卡、省份对比榜、年月热力矩阵等后续方案尚未实施。

## 本地启动与验证

使用兼容 Next.js 16 的 Node.js 环境，在仓库目录运行：

```sh
npm ci
npm run dev -- -p 3000
```

打开 <http://localhost:3000/>。

```sh
npm run test:map
npm run test:insights
npm run build
```

## 数据与范围

- 气候数据来源：[Zenodo 17542212](https://zenodo.org/records/17542212)，MPI-ESM1-2-HR / SSP2-4.5，来源数据许可 CC BY 4.0。
- 气温、比湿、短波辐射、风速和气压；2021-2030 年，距海岸不超过 100 km 的 255 个入选网格。
- 这是气候情景模拟，不是实时气象观测。省域结果仅代表该省入选沿海网格，不代表全省或城市站点。
- 网页显示使用的 JSON、CSV、地图边界和地形纹理已随仓库保存，可独立运行网站。
- 原始 NetCDF 文件、工作区外部的数据分析脚本和完整研究报告不在此网站备份中。上游数据与地图素材的权利归原权利人；仓库未另行授予这些素材的许可。

### 已随代码上传的数据

| 路径 | 内容 |
| --- | --- |
| `public/data/climate-dashboard.json` | 五项要素气候态、变化率及汇总序列 |
| `public/data/climate-evolution.json` | 2021–2030 年度网格值、坐标及省域索引 |
| `public/data/climate-monthly.json` | 2021–2030 年逐月区域统计，供热力矩阵与季节图使用 |
| `public/downloads/*.csv` | 空间网格、年度序列及月气候态三份下载表 |
| `public/data/china-*` | 完整中国边界、地形纹理与法线贴图 |
| `public/images/weather/*.png` | 四项气象主题配图 |

克隆仓库后无需重新下载原始 NetCDF 即可运行大屏。原始五个文件位于上游 Zenodo 数据集，总计约 5.38 GB，与上述网页统计数据不同。

## 恢复备份

`backup-before-insights-2026-09-02` 标签固定保存初始网站版本。后续扩展在独立开发分支进行，保留该标签不变。

本地另有同版本 ZIP 备份，27 个网站文件已逐一通过 SHA-256 比对；仓库额外提供本说明和忽略规则。
