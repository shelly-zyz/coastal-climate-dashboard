# 中国沿海气象 · 电力气候态势大屏

中国沿海地区 2021-2030 年气候投影可视化，基于 Next.js、React、Three.js 和 Recharts。

## 当前备份版本

本仓库的初始提交保存信息量扩展之前的网站，包括完整中国立体地图、连续热力颜色、年度播放、省份查询和气象统计图表。

- 点击地图仅选中省份并显示数值，不自动放大。
- 从“省份查询”下拉框选择省份时，地图自动聚焦。
- 顶部五项指标在此备份中是固定的十年均值，尚未接入年份或区域联动。
- 四张气象主题卡、省份对比榜、年月热力矩阵等后续方案尚未实施。

## 本地启动与验证

使用兼容 Next.js 16 的 Node.js 环境，在仓库目录运行：

```sh
npm ci
npm run dev -- -p 3000
```

打开 <http://localhost:3000/>。

```sh
npm run test:map
npm run build
```

## 数据与范围

- 气候数据来源：[Zenodo 17542212](https://zenodo.org/records/17542212)，MPI-ESM1-2-HR / SSP2-4.5，来源数据许可 CC BY 4.0。
- 气温、比湿、短波辐射、风速和气压；2021-2030 年，距海岸不超过 100 km 的 255 个入选网格。
- 这是气候情景模拟，不是实时气象观测。省域结果仅代表该省入选沿海网格，不代表全省或城市站点。
- 网页显示使用的 JSON、CSV、地图边界和地形纹理已随仓库保存，可独立运行网站。
- 原始 NetCDF 文件、工作区外部的数据分析脚本和完整研究报告不在此网站备份中。上游数据与地图素材的权利归原权利人；仓库未另行授予这些素材的许可。
