# 排版与边界优化

本次使用本地 Impeccable 4.1.3 的 typeset、quieter、polish 指引，按既有数据操作界面做范围内细化，不更换地图引擎、数值或色带。

- 保留已建立的中文系统字体和等宽数字，设置 12px 辅助、13px 数据表格、17px 区块标题；主题卡极窄列中的对比标签与轨迹标签保留 11px。图中密集年份轴在手机保留 10px。不存在新增远程字体请求。
- 数字启用 tabular-nums，取消过紧字距；中文主标题使用自然字距。主标题与页面 metadata 同步为“中国沿海气象可视化大屏”。
- 移除面板、主题卡及图片分隔硬边框，以背景与留白分组。保留表单、键盘焦点和选中状态等功能性反馈。
- 四张图片统一 cover 铺满，沿横向渐隐，风场不再上下留白。
- 删除重复操作指南、旧电力副标题和未标注含义的生成时间；统计口径和配图性质收纳在页脚“数据说明”，数据源与许可仍可见。

## 标识、月份与对比表

- 恢复页首标识，五项指标使用统一的柔和底色与各自图标色；主标题、区块标题、主题卡小标题和表头加粗，区块及主题卡标题前增加方向箭头。
- 省份对比表使用交替半透明行背景，不降低文字透明度。年度模式以实际较上年差值显示上升、下降或持平箭头；2021 年缺少上年数据，不生成涨跌箭头。
- 日历支持选择 2021–2030 年的任一有数据月份，保持月份高亮与月度读数，并联动地图的年度。地图仍显示年度空间统计，不将月度区域均值冒充月度空间网格。
- 月份面板支持 Escape、关闭按钮及外部点击关闭；无沿海样本时禁用。热力格仅在实际移动鼠标或键盘聚焦时预览，避免日历关闭后覆盖所选月份读数。
- 矩阵采用独立的读数行与色标行，按十行单元格实际最小高度分配空间；桌面及手机均保留读数与单元格间距。
