# 地图年度演变与省域查询

地图新增年度演变（2021—2030）、十年均值、线性变化率三种状态。年度播放支持暂停、手动年份、三档速度和循环回放，切换静态模式会停止播放。

## 数据口径

- 来源保持 MPI-ESM1-2-HR / SSP2-4.5 情景下的小时级气候投影，不是气象站观测。
- `scripts/export_map_evolution.py`（工作区根目录）从五个 NetCDF 文件重新提取原有的 255 个沿海网格，小时均值先聚合为日均，再聚合为年均。
- 新增 `public/data/climate-evolution.json`：5 个要素 × 10 年 × 255 个网格，共 12,750 个年度值；坐标顺序与原 dashboard 数据一致。
- 各要素的年度面积加权结果与原报告年度序列逐年核验，误差上限为 0.002 个显示单位。实测最大误差约 0.000049 hPa，其余要素更小。
- 省份使用现有省级 GeoJSON 对网格中心执行严格点在多边形内判断。254 个网格有明确归属；1 个未归属网格保留在全国样本中，不强行归给最近省份。
- 省域数值只代表该省入选沿海网格的余弦纬度加权均值，不代表全省平均或城市站点值。空样本省份显示“无沿海样本”。

## 渲染约定

- 地图为固定近俯视正交视角，默认保留立体侧面。关闭鼠标/触摸旋转和惯性；左键或单指拖动平移，滚轮、双指或加减按钮缩放。
- 下拉框选择或点击省份会平滑定位到该省主图范围并适度放大，整个过程不改变视角；拖动可中断定位。复位按钮回到全国范围，不改变年份或省份选择。减少动态效果偏好下直接定位。
- 省级行政区在图面固定编号 01—34；小区域可用编号对应的选择框查询，不显示悬浮省份标签。
- 城市标记仅用于地理定位；热力颜色对应 0.5° 数据网格，不宣称城市级分辨率。
- 热力显示改为连续栅格纹理：在有限邻域内做高斯加权平滑，以陆地边界裁切，仅在覆盖外缘渐隐。消除方格接缝，但不将平滑像素用于数值查询或统计。内区保留高不透明度与统一色标。
- 年度动画使用该要素全部十年网格值的统一色标；变化率采用围绕零对称的色标。颜色短暂过渡仅用于视觉平滑，数值始终取实际年度聚合值。
- 行政区挤出厚度用于示意立体视觉，不是地形高程量测。细小岛屿薄片呈现，南海岛礁及界线放在附图中，避免细长几何被拉伸为尖柱。
- 用户指定的十年样本提示框已从大屏移除；原分析结果、CSV 和报告保持不变。

## 验证

在项目目录运行 `npm run test:map`，检查全部 50 个年度帧、坐标顺序、加权统计、无样本状态和固定色标。运行 `npm run build` 检查生产构建与类型。
