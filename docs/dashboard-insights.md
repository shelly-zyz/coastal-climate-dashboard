# 大屏联动与月度数据

新版保留完整地图、固定视角、连续热力色层、省份查询和年度播放。点击地图或排名中的省份只选中并联动统计；只有地图上方的省份下拉框触发定位放大。

## 模块和口径

- 顶部五项要素是紧凑的切换入口，数值随当前模式、年份和区域变化。
- 两侧四张主题卡显示气温、比湿、近地表风速和地表向下短波辐射。数值并非发电功率。
- 年度模式中的“较上年”为当前年均值减去年均值，单位与主数值相同，不是百分比。2021 年没有上年数据。
- “较十年均值”采用原有的日加权十年气候态作基准。均值/变化率模式用“较沿海整体”，不展示无意义的同比。
- 省份排序按当前要素/模式数值降序，只包含有入选沿海网格的省级区域。排名不代表气象好坏评价，也不代表全省或站点排名。
- 年际图在未选择省份时比较北、中、南沿海；选择省份后比较该省与整体。空样本省份保留整体参考线，不填零。
- 年月矩阵包含 2021-2030 年各月实际聚合值，不是用同一组十年月气候态复制十遍。当前区域/要素的十年矩阵共用色标，切换年份不重缩放。指向或聚焦色块显示该月数值，点击只切换年度地图的年份，不将地图改为月度图。
- 季节统计按月天数加权，冬季为同一公历年的 1、2、12 月，不是跨年 DJF。横条长度使用绝对值，负值仍显示负号与冷色。
- 区域整体的季节图在年度模式下与十年均值对比；选省后与沿海整体对比。

## 月度导出

`public/data/climate-monthly.json` 由原始五个小时级 NetCDF 文件重新计算。每年逐小时数据先聚合为日均，再按公历月分组；区域统计使用余弦纬度面积权重。输出包含整体、34 个省级区域及三个纬度分区，无样本区域记录 null。

源文件的 time 属性是 `hours UTC+08`，并未提供标准 CF 绝对起点。导出程序校验小时偏移连续为 0-87647，以文件名的 2021_2030 确定起点为 2021-01-01，保持既有年度导出约定，并在输出 `timeConvention` 中说明这一假设。

程序按实际闰年日数，将十二个月重新加权还原年均值，与原有每个网格的年度导出比较。五要素的最大网格回算误差均低于 0.001 个显示单位。网站侧额外核验省份/整体年度、季节及原始分区月气候态的一致性。

```sh
python scripts/export-monthly-insights.py --data-dir C:/codex_climate_work/data/zenodo_17542212
npm run test:map
npm run test:insights
npm run build
```

Python 导出需要 numpy、netCDF4；Windows 下建议原始数据目录使用 ASCII 路径。测试和网站运行不需要原始 NetCDF。

原版恢复标签为 `backup-before-insights-2026-09-02`，本地开发分支为 `codex/dashboard-insights`。
